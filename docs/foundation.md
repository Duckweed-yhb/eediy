# 共同基础：进入任何方向之前该有的东西

> L2 的五个方向，共用同一层地基。这一页把地基拆成五块，每块只回答三个问题：**为什么需要它、够用的标准是什么、缺了去哪补**。
>
> 不是让你先把这五块学完再动手。标「必须」的先有，标「边做边补」的留到用的时候。

## 四个「必须」与三个「边做边补」

| 基础块 | 程度 | 判断标准 |
|---|---|---|
| 微积分（单变量） | **必须** | 会求导、会积分、会解一阶线性微分方程 |
| 线性代数 | **必须** | 会矩阵乘法、会解线性方程组、知道行列式的意义 |
| C 语言 | **必须** | 会用指针改调用者的变量，会用结构体组织数据 |
| 电路分析 | **必须** | 会用 KVL/KCL 与节点法算支路电流，会算 RC 时间常数 |
| 概率统计 | 边做边补 | 信号处理、电力系统方向再用 |
| 电子学（模电/数电） | 边做边补 | 做板子、看原理图时再补 |
| 电磁场 | 边做边补 | 电机、电力系统、传输线方向再用 |

「边做边补」不是「不用学」，是**不在门口挡你**。判断该补的时机：当某个推导或某个现象你解释不了，而且它正卡着下一步时，才去补。

## 数学

### 微积分（必须）

**为什么需要**：电路里的电容充放电、信号里的卷积、控制里的微分方程，全是它。

**够用的标准**：

- 看到 `dv/dt` 知道是电压变化率，能把它写成差分近似去理解离散化
- 能解 `RC·dv/dt + v = V` 这类一阶方程，得到指数衰减
- 能算定积分求功、求面积

**在哪用**：02 板块的瞬态分析、06 板块的傅里叶变换、04 板块的控制律。

**去哪补**：[01 数理与编程基础 · 微积分](/01-math-programming/README)（浙大《微积分（一）》中文入门，MIT 18.01SC 英文对照）。

### 线性代数（必须）

**为什么需要**：矩阵是电路方程、坐标变换、信号变换的统一写法。FOC 里的 Park 变换本质上是一次旋转矩阵。

**够用的标准**：

- 能写出节点法的矩阵方程 `A·x = b` 并手算一个 3×3 的解
- 知道矩阵乘法不满足交换律，并能说出这代表什么物理意义
- 知道特征值大致是什么（不要求会证），理解「沿某个方向不改变方向」的直觉

**在哪用**：02 板块的多节点电路、04 板块的坐标变换、06 板块的频域表示、05 板块的潮流计算。

**去哪补**：[01 数理与编程基础 · 线性代数](/01-math-programming/README)（MIT 18.06）。

### 概率统计（边做边补）

**为什么需要**：噪声、测量误差、随机信号、通信里的误码率。

**补的时机**：开始做信号处理实验，或要看懂「信噪比」「置信区间」时。

**去哪补**：[01 数理与编程基础 · 概率统计](/01-math-programming/README)。站内已有 [概率论与数理统计笔记](/01-math-programming/probability-statistics) 和完整 PDF。

### 复变与数学物理方程（能用到再补）

信号与系统的拉普拉斯变换、电磁场的波动方程要用。**不要提前学**：它们只在你要深入这两个方向时才成为必要条件。

## 编程：C 语言（必须）

**为什么必须**：MCU 固件、DSP 算法、Linux 下的工具链，底层都是 C。Python 用来做分析和画图，替不了它。

**够用的标准**（三条，缺一条都别进 L2）：

1. 能写一个 100 行以上、分多个函数的程序，并且自己调试通过
2. 能用指针实现一个就地交换或就地排序，并解释为什么要传地址
3. 能用 `struct` 组织一组成员的字段，用 `->` 访问

**在哪用**：03 板块全部外设驱动、04 板块的 FOC 代码、08 板块的工具链。

**去哪补**：站内 [C 语言学习笔记](/01-math-programming/c-language)（8 章，含代码与易错点），或 [Harvard CS50x 的 C 部分](/courses/cs50-c)（课程页已写清先修、投入与完成标准）。

**常见误区**：把「看得懂教程里的 C 代码」当成「会 C」。分界线是：给一个空文件和一个题目，能不能不看教程写出来。

## 物理

**必须的部分**：高中物理的电场、磁场、电磁感应直觉。没有的话，电路里「电压是电势差」「电感阻碍电流变化」这两句话会一直是死记硬背。

**用的地方**：02 板块的电容电感、04 板块的电机气隙磁场、05 板块的变压器。

**补法**：看 [01 板块的大学物理-电磁学段落](/01-math-programming/README) 的课程卡片，配合站内的 [大学物理复习笔记（热学 · 光学 · 量子）](/01-math-programming/university-physics-thermal-optics-quantum) 补需要的章节。电磁场作为独立工程课目前是本站的缺口，见 [课程体系 · 覆盖检查](/curriculum#ee-核心知识块覆盖检查)。

## 电路分析（必须）

**为什么必须**：这是 EE 的母语。后面模电、数电、电机、电力系统全都建筑在它上面。

**够用的标准**：

- 能用节点法或网孔法解一个含两个独立源的电阻网络
- 会做戴维南等效，并说清它在「带负载时电压怎么变」上的用处
- 会算 `τ = RC`，能解释 63.2% 这个数字从哪来
- 知道理想运放的虚短虚断（会用即可，不要求设计）

**在哪用**：所有硬件方向。

**去哪补**：[02 电路与电子学](/02-circuit-electronics/README) 的「电路原理」，主推荐见 [电路原理课程页](/courses/circuit-xjtu)（已核验链接、给出先修与完成标准）。

## 电子学（边做边补）

模电（二极管、BJT、MOSFET、运放、反馈）与数电（逻辑门、组合逻辑、时序、状态机）。

**补的时机**：你要设计自己的板子、要看懂芯片手册里的典型应用电路、或者要解释「为什么这个三极管开关不饱和」。

**去哪补**：[02 板块的模电/数电段落](/02-circuit-electronics/README)、[07 板块的数字逻辑部分](/07-digital-fpga/README)。

## 测量与实验动手能力

这一块不属于任何一门课，但没有它，所有实验都会变成「接线 → 不亮 → 换一个接法 → 还不亮」。

**四件必须会的事**：

| 能力 | 具体标准 | 用具 |
|---|---|---|
| 测电压与通断 | 万用表表笔位置正确，读数与理论值差 < 5% | 数字万用表 |
| 限流供电 | 电源先设限流再上电，知道为什么要串限流电阻 | 可调直流电源 / USB 供电 + 电阻 |
| 观察波形 | 示波器探头接对地，能稳定触发，读出幅值与周期 | 示波器（或借实验室的） |
| 抓数字时序 | 逻辑分析仪接上 I2C/SPI，能解出地址与数据 | USB 逻辑分析仪 + sigrok/PulseView |

**四步方法**（每次实验都这么走）：

1. **先算**：手算一个预期值，写下来（例：分压点应得 1.65 V）
2. **再仿**：LTspice 或 Python 跑一遍，确认电路或模型没接错
3. **后测**：实际接线，量出来，记录实际值
4. **最后解释差异**：差多少、为什么差（电阻公差 5%、万用表输入阻抗、面包板接触电阻、电源纹波）

**没有仪器怎么办**：用间接测量并写明限制。例：没有示波器时，用单片机定时器捕获 PWM 的高电平时间，反推占空比——这能验证频率与占空比，但看不到毛刺，也量不到上升时间。写清楚，不要假装测全了。

工具细节见 [08 硬件工具链](/08-hardware-toolchain/README)。
