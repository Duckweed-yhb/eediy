# 浙江大学 · STM32 嵌入式系统

> **定位**：一门讲清楚「寄存器到底怎么被写、外设到底怎么动」的 MCU 课。本站把它作为 [03 板块](/03-embedded-mcu/README) 主推荐的入门 MCU 课。
> **来源**：<https://www.icourse163.org/course/ZJU-1461550163>（中国大学 MOOC 课程页）｜**核验日期**：2026-11-11（访问返回 200，页面标题为「STM32嵌入式系统_浙江大学_中国大学MOOC(慕课)」）

## 学完能做什么

- 新建一个空工程，自己配时钟树、开外设，不依赖任何现成例程工程
- 写 GPIO、外部中断、定时器（定时 / PWM / 输入捕获）、UART 的初始化与使用
- 用参考手册查一个外设的寄存器位定义，并解释 HAL 库函数背后写了哪些寄存器
- 判断一个「外设不工作」的问题出在时钟、引脚复用还是配置

## 先修，以及它们在哪用

| 先修 | 用在本课的哪里 |
|---|---|
| C 语言：指针、结构体、位操作 | 寄存器访问全靠指针与位运算；HAL 的句柄是结构体 |
| 数字电路基础 | 定时器分频、中断向量、GPIO 推挽/开漏的电气含义 |
| 模拟电路常识 | ADC 采样、参考电压、输入阻抗 |
| 一块 STM32 开发板 | 课程以「奋斗 STM32 开发板」为例，同型核心板亦可 |

C 语言不够会卡在第 2 章之后。先用 [CS50x 的 C 部分](/courses/cs50-c) 或站内 [C 语言笔记](/01-math-programming/c-language) 把指针和结构体练熟。

## 主推荐与选择理由

**课程**：浙江大学《STM32嵌入式系统》（中国大学 MOOC，中文），直接入口 <https://www.icourse163.org/course/ZJU-1461550163>

**为什么选它**：

- **内容覆盖**：GPIO、中断、USART、定时器、看门狗、RTC、ADC/DAC、DMA、SPI、I2C 逐项覆盖，最后引入 uC/OS 的多任务。嵌入式常用的外设基本都在里面。
- **解释质量**：同时讲寄存器与固件库函数两条路径。对自学者来说，这是最关键的一点——只讲 HAL 会让你「会调 API 但不懂硬件」，只讲寄存器会让你写得太慢。
- **作业与实验**：课程配套实验，需要开发板。**没有板子也能看课，但外设章节必须上手**，否则等于看了一部说明书纪录片。
- **可访问性与维护**：中国大学 MOOC 平台，中文，免费旁听；课程页需人工核对最新开课批次。

**一个已知的限制**：课程示例基于「奋斗 STM32」开发板与 Keil MDK。用其他板子（Nucleo、正点原子）时需要自己改引脚与外设映射——这件事本身是很好的练习。

## 替代资源

**替代**：[电子科技大学《基于 STM32CubeMX 和 HAL 驱动库的嵌入式系统设计》](https://www.icourse163.org/course/UESTC-1207429802)（中国大学 MOOC，中文），平台页面地址同为学生可访问入口。

**差异**：

| | 浙大（本页主推荐） | 电科大（替代） |
|---|---|---|
| 路线 | 寄存器 + 固件库函数 | CubeMX 图形化 + HAL |
| 上手速度 | 慢，但底层清楚 | 快，能马上出效果 |
| 适合谁 | 想搞清楚「为什么」的人 | 想先做出东西、再回头补底层的人 |
| 硬件 | 奋斗 STM32 开发板或同型板 | Nucleo-F411RE（较易购买） |

**怎么选**：如果你已经有板子并且不急着出成果，跟浙大；如果你要在一个月内做出能演示的东西，跟电科大，然后用 ST 参考手册补寄存器。**两者都不要同时跟。**

## 教材、习题与实验

| 类型 | 名称 | 说明 |
|---|---|---|
| 教材 | 课程页「参考资料」所列教材（含《STM32 库开发实战指南》类） | 版本以课程页为准，本站未逐条核验 |
| 习题 | 课程章节测验 | 理论部分用 |
| 实验 | 课程配套外设实验 | **必须做**；需要开发板 + USB 转串口 |

**必备工具**：STM32 开发板（F103 / F411 均可）、USB 转串口模块、Keil MDK 或 STM32CubeIDE（免费）、串口助手。可选：百元级 USB 逻辑分析仪（抓 I2C/SPI 波形，极大加速排错）。

### 无板子时的降级方案

1. **纯读代码**：读懂例程、画出外设初始化流程，写下来。只能到「理解」，不能到「会做」。
2. **仿真**：Proteus 等可以模拟部分 STM32 外设，但时序与外设行为与真机有差异，**不能作为验收依据**（08 板块有 Proteus 条目）。
3. **结论**：外设这一层，没有硬件就只能到「能解释」，到不了「能实现」。如实记录你走到了哪一步。

## 完成标准

**必做**（三条，都能自测）：

1. **从空工程开始**，自己配时钟树，让一个定时器每 1 ms 中断一次并翻转 GPIO
2. UART 每秒上报一次按键计数；中断里只置标志位，主循环发送
3. 用示波器或逻辑分析仪量出 1 ms 中断周期与串口波特率，与配置一致

**选做**：

- 用 I2C 读一个传感器并按 datasheet 换算物理量
- 把某个外设的 HAL 实现手改成寄存器版本，对比两者代码量

**不算过关**：拿别人的工程改几个宏定义跑通，却说不清时钟从哪来、中断向量表在哪。
