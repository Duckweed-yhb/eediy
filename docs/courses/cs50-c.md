# Harvard CS50x · C 语言部分

> **定位**：用一门「开场就是 C」的课，把编程从语法练习拉回「用代码解决问题」。本站只用它的第 0–5 周，不跟完全程。
> **来源**：<https://cs50.harvard.edu/x/>（课程官网）｜**核验日期**：2026-11-11（访问返回 200，页面标题为 CS50x 2026）

## 学完能做什么

- 看懂一段陌生的 C 代码，说出每个变量的类型和生命周期
- 用指针穿过函数边界修改调用者的数据，并解释为什么传值做不到
- 用数组、字符串、结构体组织一个小程序的数据
- 遇到段错误时，能说出「大概率和哪一行、哪类指针问题有关」

## 先修，以及它们在哪用

| 先修 | 用在本课的哪里 |
|---|---|
| 什么都不需要 | Week 0 用图形化编程铺垫流程控制 |
| 高中数学 | 算法复杂度的粗略估算（Week 3） |
| 一台能上网的电脑 | CS50 提供云端 VS Code（cs50.dev），不必本地装编译环境 |

## 主推荐与选择理由

**课程**：Harvard CS50x（Harvard University，David J. Malan 主讲），直接入口 <https://cs50.harvard.edu/x/>

**为什么选它**：

- **内容覆盖**：Week 1 讲 C 的语法与内存模型，Week 2 数组与字符串，Week 4 指针与内存，Week 5 数据结构。这几周覆盖了嵌入式开发需要的全部 C 基础——本站只用这一段，Week 6 之后的 Python/SQL/Web 与 EE 无关。
- **解释质量**：从「内存里到底发生了什么」讲指针，而不是先讲语法再举例。这一点对后面读 MCU 寄存器尤其有用。
- **作业与实验**：Problem Set 有自动评测（`check50` / `submit50`），写完立刻知道对不对。自学最缺的就是这种即时反馈。
- **可访问性与维护**：免费旁听，无需注册即可看全部讲义与视频；开课按年更新（当前页面标为 2026 版），链接长期稳定。

## 替代资源

**替代**：站内 [C 语言学习笔记](/01-math-programming/c-language)，8 章语法骨架 + 每章可运行代码。

**差异**：笔记是中文速查，密度高、篇幅短，适合复习和查漏；但它没有作业评测，也不解释「为什么要这样设计」。**顺序建议**：先用笔记把语法过一遍，再用 CS50x 的 Week 1–5 做作业。反过来也行，只要别把两份材料都当教材逐字读。

**另一条路**：如果你更想跟着中文视频学，任何一门覆盖到「指针 + 结构体」的 C 课都可以替代，判断标准只有一条——它的作业里有没有需要你自己分配和释放内存的题。

## 教材、习题与实验

| 类型 | 名称 | 说明 |
|---|---|---|
| 教材 | 无指定教材，讲义即教材 | 课程 Notes 页，免费 |
| 习题 | Problem Set 1–5 | Week 1–5 各一题，`check50` 自动评测 |
| 实验 | CS50 的 Lab（部分周） | 以命令行程序为主，不需要硬件 |

**与你这条线的关系**：这门课只练「PC 上的 C」，不碰 MCU。做完之后你会写程序，但还不会控制硬件——那是 [嵌入式路线](/directions/embedded) S3 的事。

## 语言、访问条件、工具

- **语言**：英文授课，视频有英文字幕；国内平台有非官方搬运，但版本与作业可能对不上
- **访问**：免费（OpenCourseWare）。edX 上的验证证书需要付费，自学不需要
- **工具与硬件**：浏览器即可（cs50.dev 云端环境）；想本地跑，装 GCC 或 MinGW。不需要任何硬件

## 学习投入

- **官方数据**：课程按 11 周组织（Week 0–10），课程页未给出固定周学时
- **二手整理**：[OSSU 课程表](https://github.com/ossu/computer-science) 与 [ForrestKnight 课程表](https://github.com/ForrestKnight/open-source-cs) 都标为 10 周 / 每周 10–20 小时（这是两个第三方自学项目的整理，不是哈佛官方数据）
- **编辑估计**：**只做本站需要的 Week 1–5（C 部分）约 40–60 小时**。估算依据：5 个 Problem Set，每套含阅读、写码、调试，按每个 6–10 小时计，加视频与笔记时间。有编程基础的人会明显更快

## 完成标准

**必做**：

1. 独立完成 Week 1–5 的 Problem Set（不含抄袭，`check50` 全绿）
2. 不看教程，从空文件写一个含结构体数组、按字段排序、用指针传参的程序
3. 能解释「为什么 `scanf("%d", x)` 少了 `&` 会段错误」

**选做**：

- 用 `valgrind`（Linux）或 AddressSanitizer 找出一次自己写出的内存错误
- 把某个 Problem Set 改写成中文输入输出
