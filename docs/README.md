# 八个板块，一条能走完的路

本 Wiki 按电气工程（EE）的知识块把内容分成 8 个板块。每个板块页面再细分公开课、教材、习题实验、项目实战与自己的笔记。建议先读 [前言](/preface) 了解建站动机；**具体的学习顺序与阶段安排写在[个人博客](https://duckweed-yhb.github.io)**，本站只负责把课列清楚。

板块是**内容分类**，不是学习顺序。板块编号 01–08 不代表先学哪个。每个板块页顶部的「路线位置」只说明它和哪些板块相邻，不构成必须遵守的先后。

> 跨板块的电子书、公开课、资源网站与工具清单见 [附录](./appendix/README.md)。
>
> 你是哈工大（深圳）电气工程及其自动化专业的学生？直接看 [同校指南](https://duckweed-yhb.github.io/campus/hitsz-ee/)：课内按 12 个学期拆开，课外按竞赛、项目、实习三条线拆开。

## 推荐学习顺序

1. **01 数理与编程基础**：C 语言与高数、概率、物理并行，先把计算和第一门语言过关。
2. **02 电路与电子学**：电路原理打底，模电、数电跟进，看懂基本电路与逻辑门。
3. **06 信号与通信**：信号与系统、频域分析，为控制与滤波打基础。
4. **03 嵌入式与单片机**：在 MCU 上练外设驱动，从裸机过渡到 RTOS。
5. **04 电机与运动控制**：电机模型、FOC 与闭环控制，仿真先行、再上板实测。
6. **05 电力系统**：潮流、调度与优化算法，结合平台做集成。
7. **07 数字逻辑与 FPGA**：并行硬件描述与时序工程。
8. **08 硬件工具链**：不单独安排阶段，做项目时按需查阅。

## 填写约定

- 新增一门**课程页**：按 [`templates/course-template.md`](./templates/course-template.md) 的字段写（基本信息、课程内容、资源、教材、前置、下一步），放进 `courses/` 目录，并在对应板块页的「路线位置」补一行链接。
- 新增一份**个人笔记**：用同一模板的简化版（学习目标 + 核心内容 + 易错点），放进对应板块目录，回到该板块 README 的「我的笔记」补链接。两者别混：课程页写外部课程，笔记写自己的理解。
- 调整**学习路线**（顺序、阶段、缺口优先级）：属于个人规划，写在博客，不在本站改页；本站只改课程条目与板块归属。
- 资源条目统一写：名称 + 链接 + 一句话说明；自己的笔记放在「我的笔记」，外部课程 / 教材放在对应资源分区。
- 板块课程已按 csdiy 风格卡片格式填好；后续新增资源仍须核实真实课程主页或官方文档链接，不凭印象填写课程名或 URL。
- 资源链接要分清三种：**直接课程页 / 官方文档**、**平台入口**（如中国大学 MOOC 的课程页）、**搜索入口**（如 B 站搜索结果页）。搜索入口只用来兜底补中文视频，不能冒充课程本体；平台入口要写明「以平台页面为准」。
- 只有实际打开核验过的条目才写访问日期（如 `2026-11-11 访问确认可打开`），页面顶部不挂统一的「本页已校验」。完整规则见仓库根目录的 [CONTRIBUTING.md](https://github.com/Duckweed-yhb/eediy/blob/main/CONTRIBUTING.md)。
- 卡片里的「难度」「建议学时」一律按编辑估算写，不冒充课程官方数据；课程页里则把「官方数据」与「编辑估计」分两栏写。各板块页已在课程区顶部标明这一口径。
