# 电气不是背出来的，是接出来的

这门学科的每一条公式最后都要落到一块板子、一段代码或一台电机上。所以这里不按教材章节排，而按一条能走完的路排：先补数理与编程的地基，再进电路、嵌入式、控制与电力系统；每一页都写清楚先学什么、容易卡在哪、怎么算真的学会了。

第一次来，先看 [如何使用本站](/guide) 对号入座，再走 [一条贯通路线](/start)：四个阶段、每阶段有动手任务和过关标准。想知道八个板块之间是什么关系、共同基础有多大、五个方向怎么分，看 [课程体系](/curriculum) 与 [方向分流](/directions)。

- <span class="idx-no">01</span> **[数理与编程基础](/01-math-programming/README)** <span class="idx-gist">高数、线代、概率统计、大学物理与 C 语言。这一层决定你后面能不能读懂推导，而不是只会套公式。</span>

- <span class="idx-no">02</span> **[电路与电子学](/02-circuit-electronics/README)** <span class="idx-gist">电路原理、模拟电子技术、数字电子技术。从基尔霍夫定律一路走到运放、反馈与门电路。</span>

- <span class="idx-no">03</span> **[嵌入式与单片机](/03-embedded-mcu/README)** <span class="idx-gist">MCU 外设驱动、裸机到 RTOS，以及资源受限设备上该怎么写 C。</span>

- <span class="idx-no">04</span> **[电机与运动控制](/04-motor-control/README)** <span class="idx-gist">电机模型、FOC、电流环与速度环、逆变器与 PWM 调制。电气专业里最能把前八章串起来的一块。</span>

- <span class="idx-no">05</span> **[电力系统](/05-power-system/README)** <span class="idx-gist">潮流计算、机组组合、经济调度与多约束下的最优运行。</span>

- <span class="idx-no">06</span> **[信号与通信](/06-signal-communication/README)** <span class="idx-gist">信号与系统、通信原理、数字信号处理，以及时域与频域之间的来回换算。</span>

- <span class="idx-no">07</span> **[数字逻辑与 FPGA](/07-digital-fpga/README)** <span class="idx-gist">组合与时序逻辑、状态机、Verilog 语法与完整的 FPGA 工程流程。</span>

- <span class="idx-no">08</span> **[硬件工具链](/08-hardware-toolchain/README)** <span class="idx-gist">PCB 设计、电路仿真、测量调试、版本管理与文档工具。工具有没有顺手，直接决定你能做多快。</span>

- <span class="idx-no">—</span> **[同校指南 · 哈工大（深圳）电气](/campus/hitsz-ee/)** <span class="idx-gist">写给同一个学校、同一个专业的学弟学妹：课内按 12 个学期逐页拆开，课外分竞赛、项目、实习三条线。</span>
