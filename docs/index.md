# 电气工程学习与实践指南

面向电气与电子工程学习者，按知识块把公开课、教材、习题与工具列成索引：谁开的、讲什么、资源在哪、学完接哪门。

## 学习入口

- 第一次来：先看 [前言](/preface)，了解这个站收录什么、不收什么。
- 按知识块找内容：直接进下面的板块索引。
- 先修有缺口：[共同基础](/foundation) 列出最低限度需要补的几项，以及补法。
- 具体的学习顺序与阶段安排写在[个人博客](https://duckweed-yhb.github.io)，本站只负责把课程列清楚。

## 专业内容索引

- <span class="idx-no">01</span> **[数理与编程基础](/01-math-programming/README)** <span class="idx-gist">高数、线代、概率统计、大学物理与 C 语言。为工程建模、公式推导与数值计算提供基础。</span>

- <span class="idx-no">02</span> **[电路与电子学](/02-circuit-electronics/README)** <span class="idx-gist">电路原理、模拟电子技术、数字电子技术。覆盖网络分析、运算放大器、反馈及逻辑电路。</span>

- <span class="idx-no">03</span> **[嵌入式与单片机](/03-embedded-mcu/README)** <span class="idx-gist">MCU 外设驱动、裸机到 RTOS，以及资源受限系统的 C 语言程序设计。</span>

- <span class="idx-no">04</span> **[电机与运动控制](/04-motor-control/README)** <span class="idx-gist">电机模型、FOC、电流环与速度环、逆变器与 PWM 调制。关联电路分析、电力电子与自动控制。</span>

- <span class="idx-no">05</span> **[电力系统](/05-power-system/README)** <span class="idx-gist">潮流计算、机组组合、经济调度与多约束下的最优运行。</span>

- <span class="idx-no">06</span> **[信号与通信](/06-signal-communication/README)** <span class="idx-gist">信号与系统、通信原理、数字信号处理，以及时域与频域分析方法。</span>

- <span class="idx-no">07</span> **[数字逻辑与 FPGA](/07-digital-fpga/README)** <span class="idx-gist">组合与时序逻辑、状态机、Verilog 语法与完整的 FPGA 工程流程。</span>

- <span class="idx-no">08</span> **[硬件工具链](/08-hardware-toolchain/README)** <span class="idx-gist">PCB 设计、电路仿真、测量调试、版本管理与文档工具。支持设计验证、故障定位与工程协作。</span>

- <span class="idx-no">—</span> **[同校指南 · 哈工大（深圳）电气](https://duckweed-yhb.github.io/campus/hitsz-ee/)** <span class="idx-gist">面向本校电气工程及其自动化专业学生：课内按 12 个学期逐页拆开，课外分竞赛、项目、实习三条线。</span>
