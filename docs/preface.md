# 为什么做这个站

这个项目的起点是 [CS 自学指南](https://csdiy.wiki/)。它把课程介绍、教材、作业和学习建议放在一起，让读者在选课之前就能了解一门课的内容与要求。EEDIY 希望为电气电子方向做类似的整理。

电气电子的学习材料并不少，但它们通常分散在几种地方：教材负责推导，公开课解释概念，器件手册规定具体行为，应用笔记提供设计参考。准备做一个项目时，往往还需要自己判断这些材料之间的关系。例如，学过 PWM 并不意味着已经理解电机驱动；从定时器输出到功率级、采样和闭环控制，中间还有几层知识需要补齐。

这个站想做的，是把这些联系写清楚：一门课解决什么问题，需要哪些基础，学到什么程度适合进入下一阶段，以及可以用什么练习检查理解。

## 内容如何组织

八个板块用来存放课程与笔记，学习路线则按先修关系组织。两者不必一致：硬件工具会在多个阶段使用，数学也需要随专业课程逐步补充。没有必要先读完全部基础材料才开始实验。

[使用指南](/guide) 介绍几种常见的使用方式；[课程体系](/curriculum) 说明共同基础与专业方向；[入门实践路线](/start) 提供一组从 C 语言到 MCU 小系统的练习。已经有明确问题时，也可以直接进入对应板块查阅。

同校指南单独整理哈工大（深圳）电气专业的课程与学习安排。学校课程的开设情况应以适用年级的培养方案和教务通知为准，本站的参考安排不能替代这些文件。

## 关于推荐与笔记

课程介绍应尽量说明推荐依据：讲授范围、材料是否完整、习题和实验是否适合独立完成。学校名称和课程热度只能作为背景，不能代替这些判断。

个人笔记用于记录推导、例题和实验过程，不等于完整教材。资源链接、课程安排和工具版本也会变化；发现问题时，欢迎通过仓库 issue 提供页面位置、具体错误与可核对的来源。尚未核实的内容不应被当作确定结论。

项目使用 AI 辅助整理与编辑。由此产生的错误仍需要在维护中逐项核实和修正，不能以工具生成或构建通过作为内容准确性的证明。
